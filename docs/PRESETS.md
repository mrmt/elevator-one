# プリセット設計メモ

`PRESETS` 配列（`elevator-one.html` 内）の各プリセットが何を意図しているかの記録。
新しいプリセットを足すときは、既存のバランス感（特に `harm` と `chordrhy` の使い分け）を
壊さないための参考にする。

## 軸の考え方

プリセットは大きく2系統に分かれる。

- **ドローン系**（`harm: 0`）— 静止・霧・灰・錆・遠雷・白光・深海・圧・巡航・夜行・電磁・研磨
- **展開系**（`harm > 0`）— 大気・均衡・失調

ドローン系はさらに「シーケンスあり/なし」で分かれる。`seq: 0` のものは純粋なドローン
（静止・霧・遠雷・深海）、`seq > 0` のものはベルリン・スクール的なシーケンスを伴う。

## 各プリセットの狙い

| 名前 | seq | harm | chordrhy | 狙い |
| --- | --- | --- | --- | --- |
| 静止 stillness | 0 | 0 | .20 | 最小構成。低いドローンのみで、ほぼ動かない基準点 |
| 霧 mist | 0 | 0 | .20 | 静止より少し密度と動きを足した、輪郭のぼやけた状態 |
| 灰 ash | .18 | 0 | .20 | 中域中心、粒子（グレイン）多め。シーケンスは控えめ |
| 錆 rust | .22 | 0 | .20 | 緊張とざらつきを高めた不安定な状態 |
| 遠雷 far storm | 0 | 0 | .20 | 重い低音＋広い残響。深いが「深海」ほど無時間的ではない |
| 白光 glow | .30 | 0 | .20 | 明るさと協和を最大寄りに。シーケンスのカットオフも開き気味 |
| 深海 abyss | 0 | 0 | .20 | 最も低く遅い。ドローン系の対極（静止よりさらに動かない） |
| 圧 pressure | .45 | 0 | .20 | 密度・緊張・ざらつきが高い塊。シーケンスも密 |
| 巡航 cruise | .82 | 0 | .20 | 一定速度のシーケンス主体。緊張は低め＝安定した反復 |
| 夜行 night ride | .70 | 0 | .20 | 巡航より低速・低音寄り、レゾナンス高めで粘る質感 |
| 電磁 flux | .90 | 0 | .20 | 速く変異率も高いシーケンス。もっとも落ち着かない状態 |
| 研磨 abrasion | .38 | 0 | .20 | ざらつきを最大近くまで。質感チェーンのデモ用途も兼ねる |
| 大気 stratum | .52 | .88 | .04 | 展開系・持続コード。4小節ごとの和音、シーケンスは背景に |
| 均衡 equipoise | .74 | 1 | .78 | 展開系・刻みモード。2小節ごとの和音＋細かいリズム |
| 失調 disequilibrium | .40 | .50 | .34 | ドローンと展開の中間。両者が同時に鳴る境界線の確認用 |

「失調」は設計上とくに特殊な位置づけで、**ドローン展開と和声展開が同程度の音量で重なったときに
違和感が出るかどうかを確認するための基準プリセット**として作った（会話内で「双方が同時に鳴ると
聴感上の違和感が激しい場合は切り替え式にする」という検討があったため）。今後 `harm` 周りの
ミックスバランスを変えたら、まずこのプリセットで確認するとよい。

## 新しいプリセットを足すときの目安

- `chordrhy` は `harm` が0のときは実質無効（`chordStep` が `current.harm < .02` で早期リターンする）。
  ドローン系プリセットで値を揃えて `.20` にしてあるのは統一感のためで、意味を持たせたい場合は
  `harm` も一緒に上げること
- `seq` を上げるときはセットで `tempo` / `mutate` / `reso` / `sres` も決めること。
  `reso`（カットオフ）は上限が3200Hzなので、「白光」のように明るくしたい場合でも `.7` 程度が上限の目安
- `grit` は `GRIT_MAX`（現在0.8）で頭打ちになるため、プリセット側で1.0近くまで振っても
  実際の質感は0.8相当までしか出ない
